# 週間勤務プランナー

週間勤務表の候補作成と編集を行うデスクトップアプリです。

[最新版のインストーラーをダウンロード](https://github.com/jun5612/weekly-planner-releases/releases/latest)

## インストーラーの選び方

| PC | 選ぶファイル |
| --- | --- |
| Mac：Apple Silicon（M1以降） | `macOS-arm64.pkg` |
| Mac：Intel | `macOS-x86_64.pkg` |
| Windows：64ビット | `Windows-x64-Setup.exe` |

Macはダウンロードした.pkgを開いてApplicationsへインストールします。WindowsはSetup.exeを開き、セットアップの案内に従います。PythonやNode.jsの準備は不要です。WindowsでWebView2が未導入の場合は、セットアップ中にMicrosoftから取得するためインターネット接続が必要です。

## 初回の設定

「設定」で職員・スキル・必要人数・Google接続先を登録してください。職員情報や認証ファイルは配布物に含めません。新しいモダリティは「モダリティ管理」の5段階の案内に沿って追加できます。

## 更新する

起動時と6時間ごとに正式版を確認します。新しい版があると、お知らせと「更新する」ボタンが表示されます。

1. 設定を編集中の場合は、先に「設定を保存」を押します。
2. 「更新する」→「更新をダウンロード」を押します。
3. ダウンロードと検証の完了後、「インストーラーを開く」を押します。
4. インストールが終わったら、アプリを終了して開き直します。

更新後もPC内の勤務表・職員・設定・履歴を引き継ぎます。通知がない場合は「アプリの更新」から手動で確認できます。インターネットに接続できない場合も勤務表の編集は続けられます。

## 発行元の確認

MacのDeveloper ID署名・公証とWindowsのコード署名は未対応です。OSが発行元確認の案内を表示する場合があります。配布ファイルのSHA-256は、同じリリースの `SHA256SUMS.txt` に掲載します。
